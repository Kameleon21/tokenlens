# Getting help

Start with the [README](README.md), [usage guide](docs/usage.md), and
[release guide](docs/releases.md). Search existing issues before opening a new one.

Use the [issue forms](https://github.com/Kameleon21/tokenlens/issues/new/choose)
for reproducible bugs and feature proposals. For a usage question, open a blank
issue with a clear question, your Tokenlens version, operating system, and what
you tried. Share only synthetic or carefully redacted examples. Usage logs,
exports, and screenshots may contain private project or session names.

This is a volunteer-maintained project. There is no guaranteed response time,
implementation deadline, individual support, or long-term support for old releases.
A contribution does not create an obligation to merge it or maintain it forever.
Avoid repeated requests for status or contacting the maintainer across channels.

Security reports belong in the private channel described in [SECURITY.md](SECURITY.md).
Community behavior is covered by [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
